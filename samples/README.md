# Portfolio sample datasets

These files are synthetic examples created only for the portfolio data viewer.
They do not contain company names, customer information, real product identifiers,
or production figures.

- `market_daily_sample.csv`: normalized daily channel data
- `price_tracking_sample.json`: price collection and retry states
- `order_recommendations_sample.csv`: human-review order recommendations
- `review_analysis_sample.json`: own-product and competitor review signals
